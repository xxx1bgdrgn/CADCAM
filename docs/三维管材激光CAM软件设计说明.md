# 三维管材激光 CAM 软件设计说明

## 1. 产品目标和首版范围

开发独立的 Windows 三维激光切管 CAM 桌面程序，界面先做 Qt 版，CAD 内核继续使用 OCCT。用户可以导入 STEP 管件，也可以在软件里创建管体。确认轴线和零点后，在三维画布上选择孔、槽和管端，为各条轮廓编辑工艺，预览刀路并保存工程。控制器型号确定后，再将刀路后处理为该设备可读取的程序文件。

设计覆盖方管、圆管、椭圆管、腰形管、角钢、槽钢、工字钢、T 型钢、H 型钢和异型管材。首版建议从一种真实的等截面直管开始，用实际 STEP 样件跑通完整流程，再逐步补齐各管型的识别。装配件拆管、坡口和摆头、弯管、自动排管及整机碰撞模拟按后续阶段评估。首版管型以实际样件确认。

三维应用在 `CADCAM3D`，二维应用在 `CADCAM2D`，两者各有独立的 Visual Studio 解决方案。三维已接入单实体 STEP 导入、标准截面新建向导、实体着色和示例矩形轮廓。 [构建入口](../README.md) · [二维板材设计说明](二维板材激光CAM软件设计说明.md)

## 3. 工程内存与工作区

| 记录 | 保存的内容 |
| --- | --- |
| `tubeParts` 管件列表 | 管件 ID、名称、`Tube` 管体记录、有序 `Shape` 列表以及加工顺序。 |
| `tubeStocks` 原料管列表 | 原料 ID、管型、截面定义、长度和数量。 |
| `tubeLayouts` 排管结果列表 | 排管 ID、原料管 ID、有序摆放记录。每次摆放有自己的实例 ID，引用管件，并记录沿管轴的位置和绕轴角度。 |
| `CurrentZone` 当前工作区 | 当前视图类型、来源 ID、可渲染对象和选中对象。排管视图里的图形通过实例 ID 和源 `Shape` ID 定位。 |

几何统一使用毫米和管件局部三维坐标。建议把局部 X 轴定义为管材长度方向，Y、Z 为截面方向。管件记录原点、正向和周向零位，导入时把 STEP 的位置和单位转换到这套坐标。管件放到不同原料管上时，由摆放记录决定它的位置和角度。

`Tube` 保存整根管材或型钢的类型、来源、坐标系和对应的 OCCT 实体。`Tube.type` 决定用什么规则创建或识别管材截面，创建来源记录管体来自 STEP 还是软件内创建。`Shape.type` 决定单个孔、槽、文字或其他图形的几何和编辑方式。

列表和画布由 Qt 显示。双击条目后用源数据构建 `CurrentZone`，重绘管件、原料或排管结果。画布编辑通过 ID 写回工程记录，再刷新当前视图。选择层级包括整根管、面、边和切割轮廓。选中轮廓后，工艺面板显示该 `Shape` 的 `operations`。三维画布增加旋转和标准视角，沿用缩放、平移、点选和双向框选。

## 4. Shape 类型和三维数据

`Shape` 是可选中、可编辑的几何或群组记录。每个 `Shape` 有稳定 `id`、几何类型 `type`、对应的 `geometry` 和自己的 `operations`。管件归属由所属列表确定，跨模块单独引用时使用管件 ID 和 `Shape` ID。几何类型用于解析、显示和编辑。进入加工顺序时，再根据实际用途和轮廓校验结果确定加工动作。

| `type` | `geometry` 保存的内容 |
| --- | --- |
| `point` | 三维位置。 |
| `line` | 三维起点、终点。 |
| `arc` | 三维起点、弧上一点、终点，用于确定曲线平面和弧段。 |
| `circle` | 三维圆心、半径、所在平面的法向。需要确定默认参数起点时，用管件坐标系确定圆所在平面的参考方向。 |
| `rectangle` | 同一平面内按顺序排列的四个三维顶点。由相邻点生成四条直边和闭合轮廓。 |
| `roundedRectangle` | 局部平面坐标系、宽、高和圆角半径。局部平面记录原点及面内方向。 |
| `text` | 内容、三维插入点、字高、字体和插入点朝向。二维展开生成的文字还带有沿管壁映射的字形轮廓，用于三维预览。 |
| `ellipse` | 三维中心、长短半轴长度和平面内的长短轴方向。 |
| `ellipticalArc` | 椭圆参数、弧段起止参数和走向。 |
| `polyline` | 按顺序排列的三维直线段、圆弧段以及闭合信息。 |
| `group` | 有序的子 `Shape` 列表。各成员保留自己的 `type`、几何和工艺。群组用于整体选择与引用。 |
| `wire` | 通用 OCCT 轮廓的几何引用。用于跨面槽、样条孔口或其他需要保留原始曲线的轮廓。保存时连同所属几何一起保存。 |

内存用 `std::variant` 表达实际几何类型，文件中的 `type` 从内存类型映射得到。读取时按类型创建几何对象并校验数据。例如发现三个共线的点时，应提示该圆弧无效。STEP 里的规则轮廓通过几何校验后，可以识别为对应图元。跨圆角的槽按一条 `wire` 轮廓保存，实际曲线和顺序由 OCCT 几何表达。

### 矩形孔怎么存

下面是方管顶面 `Z = 25 mm`、宽 `30 mm`、高 `20 mm` 的矩形孔。四点从管材外侧看按顺时针排列，首尾由 `0 → 1 → 2 → 3 → 0` 相接。矩形类型已经定义边数、连接方式和闭合性，文件只需保存四个顶点。填入工艺后，仍由同一个 `Shape` 持有。

```json
{
  "id": "C07",
  "type": "rectangle",
  "geometry": {
    "vertices": [
      { "x": 100, "y": -10, "z": 25 },
      { "x": 100, "y": 10, "z": 25 },
      { "x": 130, "y": 10, "z": 25 },
      { "x": 130, "y": -10, "z": 25 }
    ]
  },
  "operations": []
}
```

JSON 示例用于说明字段结构。加载或编辑时验证四点共面、相邻边垂直、边长有效。OCCT 将四点构造成一个 `TopoDS_Wire`。矩形的面内尺寸可以从边长计算，空间位置由三维顶点确定。调整实际切割方向或切入点时，只编辑 `operations`，几何仍按约定的顶点顺序保存。

## 5. 管体创建、渲染和轮廓确认

### 两个创建入口

| 入口 | 管体几何从哪里来 | 可编辑数据 |
| --- | --- | --- |
| 导入 STEP | 由 `STEPCAFControl_Reader` 读取原始 OCCT 实体，识别管型、截面和轴线，用户可确认结果。 | 用户可调整管件基准、轮廓和工艺。识别到的截面尺寸用于显示、匹配原料和校验。 |
| 手动创建 | 标准管型按输入尺寸构造截面，异型管材由用户手绘截面。两者均沿管轴拉伸生成 OCCT 实体。 | 标准管型可编辑尺寸与长度。异型管材可编辑截面草图与长度。修改后重新生成管体，并检查已有孔槽是否仍贴合对应管面。 |

两个入口最终都生成带有 `Tube.type` 和管件坐标系的 `TubePart`，共用三维渲染、选择、工艺和刀路流程。

工具栏的「文件」提供新建、打开 STEP 和最近打开的 STEP 记录。新建向导先以截面图选择管型，再填相应的尺寸和长度。创建后的零件立即进入管件列表并显示在画布中。已知管轴的手动创建件显示两端轮廓和管端编号，右下角的视角立方体可以切换标准视角。

### Tube 类型与截面数据

| `Tube.type` | 界面类型 | 创建截面所需的数据 |
| --- | --- | --- |
| `boxTube` | 方管及矩形管 | 外宽、外高、壁厚、直角或圆角。宽高相等时是等边方管。 |
| `roundTube` | 圆管 | 外径、壁厚。 |
| `ovalTube` | 椭圆管 | 外轮廓长短轴尺寸。内轮廓可用内侧长短轴尺寸定义，也可按给定的等壁厚生成并校验向内偏移的轮廓。 |
| `obroundTube` | 腰形管 | 截面总宽、总高、壁厚。外轮廓由两条平行直线和两段半圆组成，总宽大于总高。 |
| `angleSteel` | 角钢 | 两条边的外部长度和边厚，生成 L 形材料截面。 |
| `channelSteel` | 槽钢 | 外宽、外高、腹板厚度、翼缘厚度，生成开口槽形截面。 |
| `iBeam` | 工字钢 | 截面高度、翼缘宽度、腹板和翼缘厚度，以及型号要求的斜度或圆角。 |
| `tSection` | T 型钢 | 截面高度、翼缘宽度和厚度、腹板厚度，按截面需要记录圆角。 |
| `hBeam` | H 型钢 | 截面高度、翼缘宽度、腹板和翼缘厚度、根部圆角。 |
| `customProfile` | 异型管及异型材 | 手动画的二维截面轮廓。空心异型管包含外轮廓和内轮廓，实心异型材保留外轮廓。 |

工字钢和 H 型钢保留独立的 `type`，可以共用截面构造中的几何逻辑。STEP 导入时如果仅凭几何难以区分，交由用户确认类型。

### 方管的直角和圆角

方管及矩形管共用 `boxTube`。`cornerStyle` 取 `sharp` 时，内外截面都是直角矩形。取 `rounded` 时，保存内外圆角半径。导入 STEP 时保留实际截面的圆角。在等壁厚且内外圆角同心时，可以用外圆角半径减去壁厚得到内圆角半径，并校验半径和内外边界。

下例是一根外宽 60 mm、外高 40 mm、壁厚 2 mm、长度 1000 mm 的圆角管。

```json
{
  "type": "boxTube",
  "length": 1000,
  "profile": {
    "width": 60,
    "height": 40,
    "wallThickness": 2,
    "cornerStyle": "rounded",
    "outerCornerRadius": 5,
    "innerCornerRadius": 3
  }
}
```

### 异型管手绘截面

首阶段手动创建异型管只提供手绘截面再拉伸的方式。用户在 YZ 截面视图用直线、圆弧等图元画出外轮廓和内轮廓，再输入拉伸长度。构造管体前校验每圈闭合、无自交，内轮廓完全位于外轮廓内且互不相交。仅有外轮廓时可创建实心异型材。

手绘异型管保存原始二维截面图元、拉伸长度和管件坐标系，重新打开后可以编辑截面并重建管体。异型管仍可从 STEP 导入，并保留导入的三维实体。之后在管壁上添加的孔、槽和引线继续按三维 `Shape` 及其工艺保存。

### 截面和三维渲染

截面是用垂直于管轴的平面切过管材后得到的材料区域。例如直角矩形管外宽 60 mm、外高 40 mm、壁厚 2 mm，内宽和内高分别为 56 mm 和 36 mm，内外两圈之间的区域代表管壁。方管、圆管、椭圆管、腰形管和空心异型管用内外边界生成带孔的截面。工字钢、T 型钢、H 型钢、角钢、槽钢和实心异型材用闭合的材料外边界生成截面。

手动创建时，OCCT 用 `BRepBuilderAPI_MakeFace` 在 YZ 平面建截面，再用 `BRepPrimAPI_MakePrism` 沿 X 轴拉伸成三维实体。STEP 导入的实体和拉伸生成的实体都用 `AIS_Shape` 放入 `AIS_InteractiveContext`，在 Qt 画布里着色显示。着色使用的三角网格供显示，选择面与边以及计算刀路使用 OCCT 几何。加工轮廓和刀路可作为独立线条叠加显示。 [OCCT 截面建面](https://github.com/Open-Cascade-SAS/OCCT/blob/V7_9_3/src/BRepBuilderAPI/BRepBuilderAPI_MakeFace.hxx) · [OCCT 拉伸](https://github.com/Open-Cascade-SAS/OCCT/blob/V7_9_3/src/BRepPrimAPI/BRepPrimAPI_MakePrism.hxx) · [OCCT 着色](https://github.com/Open-Cascade-SAS/OCCT/blob/V7_9_3/src/StdPrs/StdPrs_ShadedShape.cxx)

### 二维展开编辑

选中软件创建的直角或圆角方矩管，点「二维编辑」直接展开。左侧显示带独立相机的三维管件预览，右侧是二维绘图画布。1 号管端的 `+Z` 顶面中点为 `(0, 0)`，从该端看向 2 号管端，沿外截面顺时针向右量取周向距离。横轴 X 对应周向弧长，纵轴 Y 向上对应管长。顶部和左侧的毫米标尺随缩放、平移更新，竖直粗实线标出直角棱及平面和圆角的分界。设外周长为 `P`，顶面平直段半宽为 `h`，画布显示的周向范围为 `[-h, P-h]`。首面及其轮廓只在零线两侧连续显示，跨零线绘图只保存一份数据。

编辑器复用共用的二维 `ShapeRecord` 和图元。点「确定」时，保存草图以便下次编辑，并将轮廓转回三维显示。处于同一平面的轮廓可用原始点线和曲线进行精确变换，跨折角或圆角的轮廓作为同一个三维轮廓预览。圆角或跨面预览需要按目标加工精度验证后再用于刀路。点「取消」退出时保留原来的管件数据。STEP 的展开入口等导入能识别管轴及外截面后接入。

二维展开和三维视图中的普通轮廓与管端截断线均使用 `RGB(235, 235, 0)`。二维画布中，图形和截断线默认使用实线，选中后用同色虚线。上、下截断线对应管材两端，使用独立的选中类型和文字标签。删除命令只对普通图形启用，新增工艺或编辑命令可按选中类型判断适用范围。

### STEP 导入和轮廓确认

1. 用 OCCT 导入 STEP 几何，读取单位、名称和定位，显示原始模型。
2. 提取管材的主方向和截面特征。圆管可从圆柱面识别轴线与半径，方管或矩形管可结合长向外壁和端部截面判断。用户可以手动确认或修正 `Tube.type`、轴线、端部零点和周向零位。
3. 识别外壁孔口、槽和管端候选。把同一个孔或槽涉及的几条边连成一个可加工轮廓。遇到曲面参数接缝、跨面或公差不一致时，检查轮廓连接并让用户确认候选。模型接缝和实际管材焊缝分别处理。
4. 可辨认的规则轮廓保存为对应 `Shape.type`，其余轮廓使用 `wire`。用户可以补选、剔除和确认待加工轮廓。

## 6. 工艺、刀路和导出

在三维画布为一个孔添加工艺时，保存的是该孔的原始三维 `Shape` 和它的工艺参数。补偿记录偏移方向和距离，引入引出记录类型和尺寸，起点记录对应边段及该段上的相对位置，方向可单独设置。机床进给、激光功率等由机床配置和后处理管理。

```text
原始三维轮廓与工艺参数
    → 生成补偿轮廓，确定起点和走向
    → 拼接引入、切割、引出和空移
    → 根据加工顺序生成工件坐标下的三维刀路
    → 三维预览
    → 机床运动转换与控制器后处理
```

位于同一平面内的轮廓可以在该面的局部二维坐标中计算，再转回三维。圆管和方管跨面刀路按各自的截面和表面计算，展开视图从三维数据生成。跨越圆管周向零位时要维持路径连续。补偿或引线无法稳定生成时，预览应指出具体轮廓和原因，避免导出不完整的加工程序。

后处理根据已确认的设备配置把工件坐标转换为直线进给、卡盘旋转和头部运动。轴名、旋转正方向、零点、控制器格式以及机床限制以设备为准。预览生成的工件路径可先独立验收，机床轴运动预览随具体后处理一起验收。

## 7. 工程保存和撤销重做

建议三维 `.camproj` 记录 `projectKind`、`formatVersion`、单位、三个有序列表、管体定义、轮廓类型与几何、逐图形工艺、摆放和加工顺序。导入管体保存其 OCCT 实体，原始 STEP 移走后仍可打开工程。标准管型手动创建时保存截面参数和长度，异型管保存原始截面草图和长度。`wire` 等几何引用必须在重开后能够解析到同一份已保存的几何。可采用 OCAF 标签关联几何和记录，进程内地址和导入时的临时遍历序号只服务当前会话。

保存先完成临时文件写入，再替换目标文件。打开时校验项目类型、版本、几何引用和列表关联，成功后重建 `CurrentZone` 和预览数据。刀路缓存可以从已保存的几何、工艺与加工顺序重新生成。

复用 Qt 撤销栈。编辑命令保存对象 ID、变更前后的值和必要的列表位置。添加引线、调整起点、编辑轮廓和移动摆放实例都可以连续撤销或重做。查看、缩放、旋转和切换视图是交互状态。撤销后发生新编辑时，原有的后续重做记录被清除。 [Qt 撤销栈](https://doc.qt.io/qt-6.8/qundostack.html)

## 9. 实现顺序与验收

| 阶段 | 验收结果 |
| --- | --- |
| 导入与三维画布 | 一根真实 STEP 管件能正确显示和旋转。可以确认管型、轴线、零点，选择整管、一个面和一条边。 |
| 管体创建 | 可分别创建直角方管和圆角方管，按内外边界显示空腔。能手绘一个异型管截面、拉伸并检查管口。保存后重开仍可编辑截面与长度。 |
| 轮廓与工艺 | 识别并确认一个孔和一个管端。规则矩形可转成 `rectangle`，加工对象可独立设置引线、补偿和顺序。 |
| 刀路与工程恢复 | 在画布区分原始轮廓、补偿路径、引线和空移。连续撤销重做正确。保存后移走原始 STEP，重新打开仍恢复模型、轮廓和工艺。 |
| 排管与控制器输出 | 同一管件可以在一根原料管上摆放多次，各实例可独立定位。目标机床确认后，用对应的后处理和样件核对程序。 |

开始实现前需要确认首版管型和至少一份真实 STEP 样件。接入机床输出前需要确认控制器、设备轴运动方式和一份已验证的加工程序样例。
